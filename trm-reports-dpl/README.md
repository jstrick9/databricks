# Bdr Trm Reports Dpl

## TRAM to TRM ETL migration
This repository has Alteryx workflows to TRAM to TRM ETL migration.

## Description
TRAM database is now replaced by new TRM database. There are Alteryx workflows that refre to the TRAM database and tables and need to be mapped to its correspondind TRM dataset. There are 1st,2nd,3rd level Alteryx ETL workflows that are being updated for this effort. This repository contains the updated ETL workflows.
